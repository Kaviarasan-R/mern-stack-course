## Tech Stack:

### Frontend (Web):
- HTML, CSS, Javascript, Typescript
- Vite, React
- Next.js (Dave Gray: https://youtube.com/playlist?list=PL0Zuz27SZ-6PCLz7VMP2QQdeKa83rshe5&si=UL6iEeyam90q5spn)
- TailwindCSS & ShadCN (https://youtu.be/9I3JQ1q4IMk?si=2lcTzLbj_uNYhkc1)
- React Redux / Zustand (Global State Management)
- React Tanstack Query (PedroTech: https://youtu.be/mqV5OvbyXcM?si=95nonPqx8PY20ybf)
- React Hook Forms & Zod (Form Validations)

### Backend (Nest.js: https://youtu.be/8_X0nSrzrCw?si=NjGUaRzYaHgxizVx):
- Controllers, Providers, Modules, Middleware, Exception Filters, Pipes, Guards (RBAC), Interceptors, Custom Decorators
- Injection Scops, Dependency, Dynamic Modules, Custom Providers
- ORM: Prisma, TypeORM
- Task Scheduling, Queues (BullMQ), Logging, Events (Event Emitters)
- Authentication: Token Based (JWT), Session Based (OAuth2), Passport.js
- Authorization: RBAC
- Rate Limiting, Graphql API, Websockets (Pusher),  Swagger (Documentation & Testing), Postman (Documentation & Testing)
- Microservices: Queues (BullMQ) + Redis, HTTP/TCP Microservice, Apache Kafka (Confluent)
- Database: PL/SQL, PostgreSQL, Redis, AWS DynamoDB
- Testing: Jest
- Payment Gateway: Stripe, Razorpay, PhonePe
- Integrations: Nodemailer, SendGrid, Twilio
- Monorepo: Turbo monorepo, NPM monorepo, PNPM monorepo (https://github.com/Kaviarasan-R/pnpm-monorepo)
